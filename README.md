# Портфолио Юлии

Десктопный шаблон на **Next.js 16 / App Router, React, TypeScript**. Тёмная клетчатая подложка, портрет, анимированная арка, свободная сетка проектов, фильтры и подробный просмотр работ. Мобильная адаптация и тесты намеренно отложены.

## Запуск

Нужен Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Производственная сборка: `npm run build`, запуск: `npm start`.

## Что и где менять

| Содержимое | Файл |
| --- | --- |
| Имя, описание, фото, контакты, MP4 | `src/content/site.ts` |
| Проекты, категории, описания, галереи, внешние ссылки | `src/content/projects.ts` |
| Изображения работ | `public/images/projects/` |
| Видеоарка | `public/video/` |
| Цвета, размеры, сетка, эффекты | `src/app/globals.css` |
| Тексты главной, услуги | `src/app/page.tsx` |

Пустые контакты отображаются как «Скоро». Они не ведут на выдуманные адреса. Чтобы включить контакт, заполните `email`, `telegram` или `behance` в `site.ts`. Telegram и Behance ожидают полные HTTPS-ссылки.

### Настоящее фото

Добавьте фото в `public/images/`, обновите `portrait` и поставьте `portraitIsDemo: false`. Сейчас используется явно отмеченный сгенерированный демо-портрет; он не изображает настоящую Юлию.

### Видеоарка

Поместите видео в `public/video/project-arch.mp4`, задайте `archVideo: "/video/project-arch.mp4"`. При желании добавьте статическую обложку через `archPoster`. До подключения видео показывается CSS-композиция из карточек с перспективой и плавным движением. Есть кнопка паузы и поддержка системной настройки уменьшения анимации.

Для бесшовного перехода экспортируйте видео с фоном **#121413**, H.264, без звука. Обычный MP4 не поддерживает прозрачность. Если файл не загрузился, вместо пустой области возвращается арка из карточек.

### Новая работа

Скопируйте объект в массиве `projects`, задайте уникальный `slug`, название, категорию, описание, обложку и дополнительные изображения. Размеры `width` и `height` должны соответствовать исходному изображению. В `layout` выберите композицию карточки: `wide`, `portrait`, `medium`, `offset`, `last`. Первые пять карточек имеют свободную композицию, последующие автоматически выстраиваются в две колонки. При необходимости их расположение можно настроить в CSS.

`url` необязателен: внешняя ссылка появляется только при наличии адреса. У настоящей работы установите `isDemo: false`. Адрес страницы автоматически будет `/projects/ваш-slug`.

Из списка проект открывается в модальном окне: Escape, кнопка закрытия и нажатие на фон закрывают его. Прямая ссылка и обновление страницы открывают самостоятельную страницу проекта. Работают история браузера и фокус клавиатуры.

## SEO и публикация

Подготовлены серверный HTML, статические страницы проектов, метаданные, русская локаль, canonical URL, Schema.org ProfilePage/Person, Open Graph и Twitter-превью, sitemap.xml, robots.txt, favicon, понятные адреса и alt-тексты. Шрифты обслуживаются локально.

Перед публикацией:

1. Замените демонстрационные материалы и заполните контакты.
2. Создайте `.env.local` по примеру `.env.example` и задайте `NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru`.
3. Выполните `npm run build` и разместите приложение на хостинге с поддержкой Next.js.

Без `NEXT_PUBLIC_SITE_URL` шаблон имеет `noindex` и закрыт в robots.txt. Это исключает индексацию незаполненного предпросмотра. После настройки домена главная открывается для поиска. Кейсы с `isDemo: true` всегда имеют `noindex` и отсутствуют в sitemap. Реальные проекты добавляются в sitemap автоматически. Индексация также требует доступного публичного домена и времени на обход поисковиками.

## Демо-материалы

Все пять концепций вымышлены и подписаны как демонстрационные. Оригинальные SVG-макеты лежат в `public/images/projects/`; их исходный генератор — `scripts/generate-demo-assets.mjs`.

Временный портрет `public/images/demo-portrait.png` создан встроенным ImageGen. Промпт: «Black and white editorial studio portrait of an anonymous adult woman with dark bob-length hair, black sleeveless turtleneck, looking right, hand under chin, hard side light, grainy silver gelatin photograph, charcoal plain background, portrait 4:5; no text, logos or graphics». Изображение служит только заглушкой.

Базовая версия предназначена для экранов от 1120 px. Отдельных мобильных стилей, CMS, форм отправки и аналитики пока нет.
