# Портфолио Юлии

Портфолио на **Next.js 16 / App Router, React, TypeScript, Tailwind CSS 4**: анимированная арка, свободная сетка проектов и подробный просмотр работ. Основной макет рассчитан на десктоп; страница серии постеров и её карусель адаптированы под узкие экраны. Автоматизированного тестового набора пока нет.

## Запуск

Нужен Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Производственная сборка: `npm run build`, запуск: `npm start`.

Пустые контакты отображаются как «Скоро». Они не ведут на выдуманные адреса. Чтобы включить контакт, заполните `email`, `telegram` или `behance` в `site.ts`. Telegram и Behance ожидают полные HTTPS-ссылки.

### Настоящее фото

Фото задаётся полем `portrait` в `src/content/site.ts`; сейчас это `/images/julie.jpg`. Для замены добавьте файл в `public/images/` и обновите путь.

### Арка на первом экране

Арка встроена в нижнюю часть первого экрана. Шесть карточек непрерывно движутся по окружности слева направо, как в GIF-референсе. Анимация сделана на CSS, без видео, GIF-файлов и покадровых обновлений React.

Обложки и порядок задаются в `src/content/arch.ts`: шесть элементов items с уникальными id. В арке представлены все реальные работы: свадебная полиграфия, Midnight Session, Tête-à-tête, серия постеров, FORMA и баннеры о вайб-кодинге. Превью арки независимо от обложки проекта; у серии постеров используется cover.webp. durationSeconds задаёт время одного бесшовного цикла (16 секунд).

Для непрерывности шесть слотов повторяются (всего 12 квадратиков) на скрытой половине окружности. Кнопка паузы сохраняет текущую позицию. Вне экрана и на скрытой вкладке движение приостанавливается; при системной настройке уменьшения движения арка остаётся статичной. Кнопка в центре ведёт к сетке работ.

## SEO и публикация

Главная и страницы проектов отдают серверный HTML и метаданные на выбранном языке. При первом посещении язык определяется по основному языку браузера. Переключатель в шапке сохраняет выбор в cookie. У каждой работы один canonical URL, общий для обеих версий. Подготовлены Schema.org ProfilePage/Person, Open Graph и Twitter-превью, sitemap.xml, robots.txt, favicon и alt-тексты. Шрифты обслуживаются локально.

Перед публикацией:

1. Проверьте материалы проектов и заполните контакты.
2. Создайте `.env.local` по примеру `.env.example` и задайте `NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru`.
3. Выполните `npm run build` и разместите приложение на хостинге с поддержкой Next.js.

Без `NEXT_PUBLIC_SITE_URL` шаблон имеет `noindex` и закрыт в robots.txt. Это исключает индексацию незаполненного предпросмотра. После настройки домена главная открывается для поиска. Реальные проекты добавляются в sitemap автоматически. Индексация также требует доступного публичного домена и времени на обход поисковиками.

## Проекты и материалы

Первый авторский проект — [Midnight Session](https://www.behance.net/gallery/255956425/Midnight-Session-Posters-Design-Concept), рекламная афиша джазового вечера и дизайн билета. Пять опубликованных изображений сохранены в `public/images/projects/midnight-session/`; сайт загружает локальные копии, без обращений к Behance. Обложка — `cover.webp`, остальные четыре изображения используются в галерее. Проект имеет отдельную страницу `/projects/midnight-session`.

На сайте шесть реальных проектов. Демонстрационные концепции, их SVG-изображения и генератор удалены. Позиции свободной сетки заданы по slug в projectLayouts в src/components/project-grid.tsx; у каждой работы свои ширина и смещение.

Базовая версия предназначена для экранов от 1120 px; страница серии постеров и её карусель имеют отдельную адаптацию для узких экранов. CMS, форм отправки и аналитики пока нет.

### Декоративные котики

Мемные фото-стикеры размещены у портрета, в заголовке работ, в блоке «Обо мне» и в контактах.
