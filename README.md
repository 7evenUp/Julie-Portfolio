# Портфолио Юлии

Портфолио на **Next.js 16 / App Router, React, TypeScript, Tailwind CSS 4**: анимированная арка, свободная сетка проектов, фильтры и подробный просмотр работ. Основной макет рассчитан на десктоп; страница серии постеров и её карусель адаптированы под узкие экраны. Автоматизированного тестового набора пока нет.

## Запуск

Нужен Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Производственная сборка: `npm run build`, запуск: `npm start`.

## Что и где менять

| Содержимое                                            | Файл                          |
| ----------------------------------------------------- | ----------------------------- |
| Имя, описание, фото, контакты                         | `src/content/site.ts`         |
| Восемь обложек арки и скорость цикла                  | `src/content/arch.ts`         |
| Проекты, категории, описания, галереи, внешние ссылки | `src/content/projects.ts`     |
| Изображения работ                                     | `public/images/projects/`     |
| Цвета, шрифты, анимации и сложные эффекты             | `src/app/globals.css`         |
| Размеры, сетка, состояния и переходы макета           | Tailwind-классы в компонентах |
| Секции главной, тексты и услуги                       | `src/app/sections/`           |

Пустые контакты отображаются как «Скоро». Они не ведут на выдуманные адреса. Чтобы включить контакт, заполните `email`, `telegram` или `behance` в `site.ts`. Telegram и Behance ожидают полные HTTPS-ссылки.

### Настоящее фото

Фото задаётся полем `portrait` в `src/content/site.ts`; сейчас это `/images/julie.jpg`. Для замены добавьте файл в `public/images/` и обновите путь.

### Арка на первом экране

Арка встроена в нижнюю часть первого экрана. Восемь карточек непрерывно движутся по окружности слева направо, как в GIF-референсе. Анимация сделана на CSS, без видео, GIF-файлов и покадровых обновлений React.

Обложки и порядок задаются в `src/content/arch.ts`: восемь элементов `items`, у каждого уникальный `id` и путь к изображению в `image`. Здесь уже есть Midnight Session, Tête-à-tête и серия постеров, а также демонстрационные материалы. Превью арки независимо от обложки проекта: у Tête-à-tête используется отдельный `arch.webp`, у серии постеров — `cover.webp`. Заменяйте оставшиеся демо-слоты реальными работами по мере наполнения. `durationSeconds` задаёт время одного бесшовного цикла (по умолчанию 16 секунд).

Для непрерывности восемь слотов повторяются на скрытой половине окружности. Кнопка паузы сохраняет текущую позицию. Вне экрана и на скрытой вкладке движение приостанавливается; при системной настройке уменьшения движения арка остаётся статичной. Кнопка в центре ведёт к сетке работ.

## SEO и публикация

Подготовлены серверный HTML, статические страницы проектов, метаданные, русская локаль, canonical URL, Schema.org ProfilePage/Person, Open Graph и Twitter-превью, sitemap.xml, robots.txt, favicon, понятные адреса и alt-тексты. Шрифты обслуживаются локально.

Перед публикацией:

1. Замените демонстрационные материалы и заполните контакты.
2. Создайте `.env.local` по примеру `.env.example` и задайте `NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru`.
3. Выполните `npm run build` и разместите приложение на хостинге с поддержкой Next.js.

Без `NEXT_PUBLIC_SITE_URL` шаблон имеет `noindex` и закрыт в robots.txt. Это исключает индексацию незаполненного предпросмотра. После настройки домена главная открывается для поиска. Кейсы с `isDemo: true` всегда имеют `noindex` и отсутствуют в sitemap. Реальные проекты добавляются в sitemap автоматически. Индексация также требует доступного публичного домена и времени на обход поисковиками.

## Проекты и материалы

Первый авторский проект — [Midnight Session](https://www.behance.net/gallery/255956425/Midnight-Session-Posters-Design-Concept), рекламная афиша джазового вечера и дизайн билета. Пять опубликованных изображений сохранены в `public/images/projects/midnight-session/`; сайт загружает локальные копии, без обращений к Behance. Обложка — `poster.webp`, остальные четыре изображения используются в галерее. Проект имеет `isDemo: false` и отдельную страницу `/projects/midnight-session`.

Все пять концепций вымышлены и подписаны как демонстрационные. Оригинальные SVG-макеты лежат в `public/images/projects/`; их исходный генератор — `scripts/generate-demo-assets.mjs`.

Базовая версия предназначена для экранов от 1120 px; страница серии постеров и её карусель имеют отдельную адаптацию для узких экранов. CMS, форм отправки и аналитики пока нет.

### Декоративные котики

Мемные фото-стикеры размещены у портрета, в заголовке работ, в блоке «Обо мне» и в контактах. Локальные WebP-файлы с прозрачностью лежат в `public/images/stickers/`, выбор котика, размеры и повороты задаёт `src/components/cat-sticker.tsx`. В `src/components/cat-sticker.module.css` осталась только обводка прозрачного силуэта из нескольких теней. Стикеры не перехватывают нажатия и скрыты от скринридеров.
